Label vs. weights

Every gateway label is a claim. Black-box testing cannot see the weights, so this skill collects evidence for and against the claim, and says when the question is still open.

How a run goes

30 seconds Price check. Opus at $0.001/M is a story, not a model.
2 to 3 minutes Wrapper and service audit: fields, headers, token overhead, hidden caps.
3 to 5 minutes Seedable battery plus a 120,000-character needle at two depths.
1 minute Identity and cutoff, sampled twice. Only a contradiction counts.

The fifth step needs the official key: the same prompts against the vendor endpoint, compared at temperature 0. It is the strongest check a user can run, and it still cannot prove weights.

Probe reference

One flag selects each family. The default set is infra, service, caps, self.

Infrastructure and service

  • --probes infrawrapper fields, x-headers, catalog, token overhead
  • --probes servicehidden caps, response mutation, reasoning passthrough
  • --probes capsseedable battery, dual-depth needle at 25% and 75%
  • --probes selfidentity and cutoff, sampled twice

Differential

  • --baseline-basesame prompts against the official endpoint, temperature 0
  • --logprobstop-1 next token, delta logprob, needs both routes

Reports

  • --seed Nreproduce the battery and needle exactly
  • --out file.jsonfull machine-readable report, keys never written
