Tolerance: max(2, ceil(0.08 x reference)). Weak evidence: same dialect, not the same weights.

Usage numbers are testimony, not measurement. A signature match gates the counting dialect; it never proves the weights. Re-run with fresh texts before concluding anything.

How a run goes

  1. Control. One prompt-only request carrying the single character "a".
  2. Probe set. Five prompt-only requests: mixed-script prose, Javanese with a price, a code one-liner, Chinese with emoji, Arabic with symbols.
  3. Subtract. delta(T) = tokens(T) - tokens("a"), so the path's template and system-prompt overhead cancels out.
  4. Compare. Each delta against the measured signature of the claimed model's family.
  5. Read. Four or five of five texts agree, and you have a signature match. Weak evidence, but evidence.

Provenance: the reference signatures were measured on 2026-10-29 on a text set of the same composition (id+accuse, jv+price, code, cjk+emoji, arab+misc); the exact strings live only on the audit machine. The collector's built-in texts are public stand-ins with the same composition, so an exact match is indicative, and a deviation has to be re-measured before it counts.

Probe reference

One command, three required inputs. Flags only tune the run.

The three inputs

  • --basegateway root, e.g. https://gw.example.com/v1
  • --modelthe model id the gateway claims to serve
  • --keyor env VERIFY_API_KEY; never printed, never written to the report

Repeats

  • --repeat Nrepeat the probe set, catches unstable usage accounting

Report

  • --out FILEfull JSON report, keys never written

Pacing

  • --sleep Sseconds between requests, default 2
  • --timeout Sper-request timeout, default 60
  • retriesa dropped request is tried three times, and a reasoning route that answers 502 climbs a max_tokens ladder, 64 then 512 then 2048

Offline

  • selftestoffline check, no key, no network

Eight verdicts.

Signature match
All five texts agree with the claimed family's signature. Weak evidence: same dialect, not the same weights.
Partial match
Four of five agree. One text that misses is an anomaly, not a family split. Re-run with fresh texts.
Signature mismatch
Three or fewer agree. The tokenizer does not look like that family.
Unmeasured family
No reference for the claimed model. The deltas are reported raw.
Unstable accounting
The control count moved between repeats. Nothing can be concluded.
Probe incomplete
The route answered but some texts could not be measured. The deltas are partial, so no verdict is drawn.
Endpoint unavailable
Timeout, refusal or an HTTP error. Dead is not fake, and neither is a refusal.
No usage reported
The gateway returned no token usage, so the method could not run.
